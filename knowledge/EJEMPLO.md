# Como usar esta carpeta

Pon aqui archivos `.md` con toda la informacion real de tu negocio: preguntas frecuentes,
catalogo de productos/servicios, politicas, procesos de venta o soporte, etc.

Todo el contenido de los archivos `.md` en esta carpeta se carga tal cual (verbatim) dentro del
system prompt del bot al arrancar - es la unica fuente de verdad que el bot usa para responder.
Si algo no esta escrito aqui, el bot no debe inventarlo, debe escalar a un humano.

Sugerencia de archivos (no obligatorio, cada proyecto puede tener los que necesite):
- `FAQ.md` - preguntas frecuentes
- `Company.md` - quienes son, que hacen
- `Products.md` - catalogo de productos o servicios
- `Policies.md` - politicas (cancelaciones, garantias, etc.)
- `SalesPlaybook.md` - como manejar preguntas de venta
- `SupportPlaybook.md` - como manejar preguntas de soporte
- `Processes.md` - procesos internos relevantes para el bot
- `Integrations.md` - que otras herramientas usa el negocio (si aplica)

Borra este archivo (EJEMPLO.md) cuando agregues los archivos reales de tu proyecto.
